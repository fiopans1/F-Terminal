# Shortcuts

> [Documentation](README.md) · [Español](../es/atajos.md)

## Global — macOS

| Action | Shortcut |
|---|---|
| New terminal (default profile) | `Cmd+T` |
| Choose shell profile | `Cmd+Shift+N` |
| Close pane / terminal | `Cmd+W` / `Cmd+Shift+W` |
| Split right / down | `Cmd+D` / `Cmd+Shift+S` |
| Switch terminal | `Cmd+Shift+[` / `]`, `Cmd+1..9`, `Ctrl+Tab` |
| Rename active session | `F2` |
| Move focus between panes | `Cmd+Alt+arrows`, <kbd>Cmd+&#96;</kbd> |
| Show/hide sidebar | `Cmd+B` |
| Switch Sessions / Files | `Cmd+Shift+E` |
| Search scrollback | `Cmd+Shift+F` |
| Open link under cursor | `Cmd+Click` |
| Open Code Review | `Cmd+Shift+R` |
| Open Git manager | `Cmd+Shift+M` |
| Open Agents | `Cmd+Shift+A` |
| Open settings (`config.toml`) | `Cmd+Shift+P` |
| Open system file explorer | `Cmd+Shift+O` |
| Save in the editor | `Cmd+S` |
| Close editor | `Esc` or `Cmd+W` |
| Copy / paste | `Cmd+C` / `Cmd+V` |
| Clear terminal | `Cmd+K` |
| Increase / decrease / reset font size | `Cmd+=` / `Cmd+-` / `Cmd+0` |

## Global — Linux / Windows

| Action | Shortcut |
|---|---|
| New terminal (default profile) | `Ctrl+Shift+T` |
| Choose shell profile | `Ctrl+Shift+N` |
| Close pane | `Ctrl+Shift+W` |
| Split right / down | `Ctrl+Shift+D` / `Ctrl+Shift+S` |
| Switch terminal | `Ctrl+Tab`, `Ctrl+Shift+Tab`, `Ctrl+Shift+[ / ]` |
| Rename active session | `F2` |
| Move focus between panes | `Ctrl+Alt+arrows`, <kbd>Ctrl+Shift+&#96;</kbd> |
| Show/hide sidebar | `Ctrl+Shift+B` |
| Switch Sessions / Files | `Ctrl+Shift+E` |
| Search scrollback | `Ctrl+Shift+F` |
| Open link under cursor | `Ctrl+Click` |
| Open Code Review | `Ctrl+Shift+R` |
| Open Git manager | `Ctrl+Shift+M` |
| Open Agents | `Ctrl+Shift+A` |
| Open settings (`config.toml`) | `Ctrl+Shift+P` |
| Open system file explorer | `Ctrl+Shift+O` |
| Save in the editor | `Ctrl+S` |
| Close editor | `Esc` or `Ctrl+W` |
| Copy / paste | `Ctrl+Shift+C` / `Ctrl+Shift+V`, `Ctrl+Insert` / `Shift+Insert` |
| Clear terminal | `Ctrl+Shift+K` |
| Increase / decrease / reset font size | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |

The terminal font size can be changed live with those shortcuts. The value is
saved automatically to `font_size` in `config.toml`; `0` restores the default
(14 pt).

`Shift+Enter` sends a linefeed (`LF`) to the terminal, which is what OpenCode,
Claude Code and Codex use to insert a line break in the prompt. `Ctrl+J` and
`Alt+Enter` also work as alternatives.

## Shell selector

| Action | Key |
|---|---|
| Move selection | `↑` / `↓` |
| Go to first / last | `Home` / `End` |
| Create terminal with the profile | `Enter` |
| Close selector | `Esc` |

## Code Review

| Action | Key |
|---|---|
| Move through reviews/PRs/files | `↑` / `↓`, `PgUp` / `PgDn` |
| Open review or PR | `Enter` |
| Search PRs | `/` or `Cmd/Ctrl+F` |
| Mark file as reviewed | `Space` or `M` |
| Switch panel | `Tab` |
| Refresh | `R` |
| Leave the search box | `Esc` |
| Close window | `Esc` or `×` |

## Git manager

| Action | Key |
|---|---|
| Switch panel | `Tab` |
| Navigate lists | `↑` / `↓`, `PgUp` / `PgDn`, `Home` / `End` |
| Stage / unstage | `Enter` or `Space` |
| Discard changes | `Del` or `Backspace` |
| Checkout / open stash | `Enter` |
| New branch | `N` |
| Merge | `M` |
| Delete branch | `D` |
| Refresh | `R` |
| Commit | `Enter` in the message field |
| Close window | `Esc` or `Cmd/Ctrl+W` |

## Agent Mode

| Action | Key |
|---|---|
| Move selection | `↑` / `↓`, `J` / `K`, `PgUp` / `PgDn`, `Home` / `End` |
| Focus the agent's pane | `Enter` or double-click |
| Quick reply / approve | `I` / `Y` |
| Search | `/` or `Cmd/Ctrl+F` |
| Change filter / origin / order | `Tab`, `F`, `1`–`4` / `E` / `S` |
| Inspector tabs | `[` / `]` |
| Agent launcher | `N`; `1`–`4` |
| Refresh processes | `R` or `F5` |
| Kill process (double press) | `X`, `Del` or `Backspace` |
| Close window | `Esc`, `Cmd/Ctrl+W` or `×` |
